# DiceModders

This site is intended for the documentation of DiceKingdoms in order to make modding the game easier.

## Where to start

- **Playing with mods:** [Mods Installation](guides/mod-installation.md).
- **Writing a mod:** [Project Setup](guides/modding/project-setup.md), then [IL2CPP tips](guides/modding/il2cpp-tips.md).
- **Mod libraries:** [UiKit](guides/modding/uikit.md) builds windows, top bar buttons and settings rows from the game's own UI; [ModCore](guides/modding/modcore.md) handles the Steam lobby,
  host-controlled lobby rules, desync warnings and civilizations; [ModBridge](guides/modding/modbridge.md) shows ModCore's data on UiKit's screens and explains who depends on what.
- **How the game works:** the *Game architecture* section: [Island generation](game-architecture/island-generation.md), [Resources](game-architecture/resources.md),
  [Game UI](game-architecture/ui.md), [Rules and civilizations](game-architecture/rules-and-civilizations.md), [Civilizations in the game code](game-architecture/civilizations.md), [Island code](game-architecture/island-code.md),
  [Meteorites](game-architecture/meteorites.md) and [Reverse-engineering notes](game-architecture/reverse-engineering.md).
- **Adding a civilization:** [Making a civilization](guides/modding/making-a-civilization.md).
- **Sharing your mod:** [Publishing a mod](guides/modding/publishing.md).
